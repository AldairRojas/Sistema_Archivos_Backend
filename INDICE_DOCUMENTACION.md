## 🆘 SI ALGO NO FUNCIONA

### Paso 1: Verificar
```
¿Es un error 401? → Token ausente o inválido
¿Es un error 422? → Validación fallida, revisar "errors"
¿Es un error 404? → Recurso no encontrado, verificar ID
¿No trae datos? → Revisar headers y token
```

### Paso 2: Consultar
```
1. Buscar en INICIO_RAPIDO.md - "Errores comunes"
2. Revisar FRONTEND_GUIDE.md - "Errores comunes"
3. Leer README.md - "Solución de problemas"
4. Verificar ejemplos en EJEMPLOS_PETICIONES.md
```

### Paso 3: Probar
```
1. Probar endpoint en Postman
2. Verificar body y headers
3. Confirmar token válido
4. Revisar validaciones requeridas
```
